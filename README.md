# 🌾 Smart Crop Assistant

> AI-powered agriculture application for crop recommendation, yield prediction, and plant disease detection.

---

## Project Status

🟡 **Phase 1 — Development Environment Setup**

This project is being built as a learning exercise in professional AI/ML software engineering.

## Features (Planned)

- **Crop Recommendation** — Input soil parameters (N, P, K, pH, rainfall, temperature, humidity) and receive ranked crop suggestions with confidence scores.
- **Plant Disease Detection** — Upload a leaf image and receive disease diagnosis with treatment recommendations.
- **Yield Prediction** — Estimate harvest output based on soil, crop, and weather parameters.
- **Prediction History** — Dashboard of past predictions and analytics.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Python 3.14, FastAPI, Pydantic v2 |
| ML | Scikit-learn, XGBoost, PyTorch |
| Database | SQLite (dev), PostgreSQL (prod) |
| Frontend | React 18, TypeScript, Tailwind CSS, Vite |
| DevOps | Docker, GitHub Actions |
